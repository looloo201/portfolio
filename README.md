# 웹 퍼블리셔 대표 포트폴리오

## 파일 구성
- `index.html`: 홈페이지 콘텐츠와 구조
- `styles.css`: PC/모바일 반응형 스타일 및 PDF 인쇄 스타일
- `script.js`: 프로젝트 링크, 모바일 메뉴, PDF 인쇄, 이메일 설정

## 시작하기
1. 세 파일을 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 열어 확인합니다.
3. `script.js` 상단 `CONFIG.projects`에 각 프로젝트의 실제 GitHub Pages URL을 입력합니다.
4. `CONFIG.email`에 공개할 이메일을 입력합니다.
5. `index.html`에서 소개, 프로젝트 설명, 경력 날짜 등을 실제 이력에 맞게 수정합니다.
6. GitHub 저장소 루트에 세 파일을 업로드합니다.
7. 저장소 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

## PDF로 저장
상단 'PDF 저장' 버튼 → 인쇄 대화상자 → 대상: PDF로 저장 → 저장.
브라우저 인쇄 설정에서 '배경 그래픽'을 켜면 색상과 썸네일이 유지됩니다.

## 주의
- 롯데카드만 기존 대화에서 확인된 URL로 설정했습니다. 나머지 3개 URL은 반드시 직접 입력해 주세요.
- 프로젝트 썸네일은 실제 고객사 운영 화면이 아니라 HTML/CSS로 제작한 콘셉트 이미지입니다.
- IGS 등 프로젝트 세부 경력, 이메일은 제출 전에 사실관계를 확인하고 수정하세요.
- Google Fonts를 사용하므로 최초 접속 시 폰트 로딩에 인터넷이 필요합니다. 로딩되지 않아도 시스템 폰트로 표시됩니다.
